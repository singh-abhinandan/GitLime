## Overview

GitLime is a lead management and business automation platform designed to help service-based businesses manage leads, streamline customer communication, and simplify appointment scheduling.

The platform brings lead management, WhatsApp automation, AI-powered follow-ups, and booking management together in one place, helping businesses improve customer engagement and manage their operations more efficiently.

This repository contains the frontend implementation of GitLime, built using React and modern frontend technologies.

## Key Product Capabilities

- **Lead Management:** Organize and manage incoming customer leads.
- **WhatsApp Automation:** Streamline customer communication through WhatsApp.
- **AI-Powered Follow-ups:** Support automated and intelligent customer follow-up workflows.
- **Appointment Scheduling:** Simplify appointment booking and scheduling.
- **Booking Management:** Manage customer bookings through a centralized experience.
- **Business Automation:** Reduce repetitive operational tasks through automated workflows.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/gitlime.git
```

**2. Navigate to the project directory**

```bash
cd gitlime
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

The application will be available at the local URL provided by Vite, usually:

```text
http://localhost:5173
```
